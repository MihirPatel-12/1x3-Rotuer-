# 1x3-Rotuer-
A parameterizable 1-input / 3-output packet router (Verilog RTL), verified with a self-checking, layered SystemVerilog testbench — scoreboard, functional coverage, mailboxes, and a driver/monitor/generator architecture. 266/266 data checks and 40/40 error-flag checks passing, 100% signal coverage, 96.67% transaction coverage.
